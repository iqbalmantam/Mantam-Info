# Mantam Info

Satu aplikasi HTML untuk berita, TV, dan radio dari seluruh Indonesia, ditambah cuaca (Open-Meteo) dan gempa (BMKG).

Cukup satu file: `index.html`. Buka langsung di browser, atau hosting lewat GitHub Pages.

Sumber data: ANTARA, detikcom, CNN Indonesia, Tempo, Republika, Suara.com, Google Berita, BMKG, Open-Meteo, iptv-org, Radio Browser.

Daftar TV diperiksa otomatis di browser: hanya kanal yang manifest siarannya terbaca yang ditampilkan, dan kanal yang gagal diputar langsung dihapus dari daftar.

## Pasang di HP (PWA)

Buka alamat GitHub Pages di Chrome, lalu pilih menu ⋮ → **Pasang aplikasi** / **Tambahkan ke layar utama**. Di iPhone: Safari → Bagikan → **Tambah ke Layar Utama**. Kerangka aplikasi tersimpan untuk mode offline; berita, TV, dan radio tetap butuh internet.
